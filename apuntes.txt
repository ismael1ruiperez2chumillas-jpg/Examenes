--- PROBLEMA 1 ---

Campo de desplazamientos:

u = 4*a*x^2
v = 8*a*z^2
w = -2*a*y^2

Dato:

a = 10^-4 m^-1

E = 210 GPa
nu = 0.3

Se pide:

1) Matriz de deformacion.
2) Tensor de tensiones.
3) Circulos de Mohr.

------------------------------------------------------------

--- 1) MATRIZ DE DEFORMACION ---

En pequenas deformaciones, la matriz de deformacion es:

eps_xx = du/dx
eps_yy = dv/dy
eps_zz = dw/dz

eps_xy = 1/2*(du/dy + dv/dx)
eps_xz = 1/2*(du/dz + dw/dx)
eps_yz = 1/2*(dv/dz + dw/dy)

------------------------------------------------------------

Derivamos cada desplazamiento:

u = 4*a*x^2

du/dx = 8*a*x
du/dy = 0
du/dz = 0

v = 8*a*z^2

dv/dx = 0
dv/dy = 0
dv/dz = 16*a*z

w = -2*a*y^2

dw/dx = 0
dw/dy = -4*a*y
dw/dz = 0

------------------------------------------------------------

Ahora sustituimos:

eps_xx = du/dx = 8*a*x

eps_yy = dv/dy = 0

eps_zz = dw/dz = 0

eps_xy = 1/2*(du/dy + dv/dx)
eps_xy = 1/2*(0 + 0) = 0

eps_xz = 1/2*(du/dz + dw/dx)
eps_xz = 1/2*(0 + 0) = 0

eps_yz = 1/2*(dv/dz + dw/dy)
eps_yz = 1/2*(16*a*z - 4*a*y)

eps_yz = 8*a*z - 2*a*y

------------------------------------------------------------

Por tanto, la matriz de deformacion queda:

        | 8*a*x        0              0        |
eps =   |   0          0        8*a*z - 2*a*y |
        |   0    8*a*z - 2*a*y        0       |

------------------------------------------------------------

Como a = 10^-4:

eps_xx = 8*10^-4*x

eps_yz = 8*10^-4*z - 2*10^-4*y

eps_yz = 10^-4*(8*z - 2*y)

------------------------------------------------------------

--- 2) TENSOR DE TENSIONES ---

Usamos la formula dada en el enunciado:

sigma_ij =
E*nu/((1+nu)*(1-2*nu))*eps_kk*delta_ij
+
E/(1+nu)*eps_ij

Primero calculamos eps_kk:

eps_kk = eps_xx + eps_yy + eps_zz

eps_kk = 8*a*x + 0 + 0

eps_kk = 8*a*x

------------------------------------------------------------

Calculamos las constantes elasticas:

E = 210 GPa
nu = 0.3

A = E*nu/((1+nu)*(1-2*nu))

A = 210*0.3/((1+0.3)*(1-2*0.3))

A = 63/(1.3*0.4)

A = 63/0.52

A = 121.15 GPa

------------------------------------------------------------

B = E/(1+nu)

B = 210/(1+0.3)

B = 210/1.3

B = 161.54 GPa

------------------------------------------------------------

La formula queda:

sigma_ij = A*eps_kk*delta_ij + B*eps_ij

sigma_ij = 121.15*eps_kk*delta_ij + 161.54*eps_ij

------------------------------------------------------------

Tension normal sigma_xx:

sigma_xx = A*eps_kk + B*eps_xx

sigma_xx = 121.15*(8*a*x) + 161.54*(8*a*x)

sigma_xx = (121.15 + 161.54)*8*a*x

sigma_xx = 282.69*8*a*x

sigma_xx = 2261.52*a*x GPa

Como a = 10^-4:

sigma_xx = 2261.52*10^-4*x GPa

sigma_xx = 0.22615*x GPa

sigma_xx = 226.15*x MPa

------------------------------------------------------------

Tension normal sigma_yy:

sigma_yy = A*eps_kk + B*eps_yy

sigma_yy = 121.15*(8*a*x) + 161.54*0

sigma_yy = 969.20*a*x GPa

Como a = 10^-4:

sigma_yy = 0.09692*x GPa

sigma_yy = 96.92*x MPa

------------------------------------------------------------

Tension normal sigma_zz:

sigma_zz = A*eps_kk + B*eps_zz

sigma_zz = 121.15*(8*a*x) + 161.54*0

sigma_zz = 969.20*a*x GPa

Como a = 10^-4:

sigma_zz = 0.09692*x GPa

sigma_zz = 96.92*x MPa

------------------------------------------------------------

Tensiones tangenciales:

sigma_xy = B*eps_xy

sigma_xy = 161.54*0 = 0

sigma_xz = B*eps_xz

sigma_xz = 161.54*0 = 0

sigma_yz = B*eps_yz

sigma_yz = 161.54*(8*a*z - 2*a*y)

sigma_yz = 161.54*a*(8*z - 2*y) GPa

Como a = 10^-4:

sigma_yz = 0.016154*(8*z - 2*y) GPa

sigma_yz = 16.154*(8*z - 2*y) MPa

sigma_yz = 129.23*z - 32.31*y MPa

------------------------------------------------------------

Por tanto, el tensor de tensiones es:

             | 226.15*x        0              0        |
sigma MPa =  |    0        96.92*x      tau_yz        |
             |    0         tau_yz      96.92*x       |

donde:

tau_yz = 129.23*z - 32.31*y MPa

------------------------------------------------------------

--- 3) CIRCULOS DE MOHR ---

El tensor de tensiones tiene esta forma:

             | sigma_x     0        0     |
sigma =      |   0      sigma_y   tau_yz |
             |   0       tau_yz  sigma_z |

con:

sigma_x = 226.15*x MPa

sigma_y = 96.92*x MPa

sigma_z = 96.92*x MPa

tau_yz = 129.23*z - 32.31*y MPa

------------------------------------------------------------

Como sigma_y = sigma_z y solo hay tau_yz,
el eje x ya es una direccion principal.

Entonces una tension principal es:

sigma_1 = sigma_x

sigma_1 = 226.15*x MPa

------------------------------------------------------------

Las otras dos tensiones principales salen del bloque y-z:

        | sigma_y   tau_yz |
        | tau_yz   sigma_z |

Como sigma_y = sigma_z:

sigma_2 = sigma_y + tau_yz

sigma_3 = sigma_y - tau_yz

Por tanto:

sigma_2 = 96.92*x + tau_yz

sigma_3 = 96.92*x - tau_yz

Sustituyendo tau_yz:

sigma_2 = 96.92*x + 129.23*z - 32.31*y

sigma_3 = 96.92*x - 129.23*z + 32.31*y

Todo en MPa.

------------------------------------------------------------

--- RESUMEN TENSIONES PRINCIPALES ---

sigma_1 = 226.15*x

sigma_2 = 96.92*x + 129.23*z - 32.31*y

sigma_3 = 96.92*x - 129.23*z + 32.31*y

Unidades: MPa

------------------------------------------------------------

--- CIRCULO DE MOHR ENTRE sigma_2 Y sigma_3 ---

Centro:

C_23 = (sigma_2 + sigma_3)/2

C_23 = 96.92*x MPa

Radio:

R_23 = abs((sigma_2 - sigma_3)/2)

R_23 = abs(tau_yz)

R_23 = abs(129.23*z - 32.31*y) MPa

------------------------------------------------------------

--- CIRCULO DE MOHR ENTRE sigma_1 Y sigma_2 ---

Centro:

C_12 = (sigma_1 + sigma_2)/2

Radio:

R_12 = abs(sigma_1 - sigma_2)/2

------------------------------------------------------------

--- CIRCULO DE MOHR ENTRE sigma_1 Y sigma_3 ---

Centro:

C_13 = (sigma_1 + sigma_3)/2

Radio:

R_13 = abs(sigma_1 - sigma_3)/2

------------------------------------------------------------

--- DIBUJO ESQUEMATICO ---

Eje horizontal: sigma
Eje vertical: tau

        tau
         |
         |
         |        ooooooooo
         |     ooo         ooo
         |   oo               oo
---------+-------------------------- sigma
         |   oo               oo
         |     ooo         ooo
         |        ooooooooo
         |

Hay 3 circulos de Mohr:

Circulo 12: entre sigma_1 y sigma_2
Circulo 13: entre sigma_1 y sigma_3
Circulo 23: entre sigma_2 y sigma_3

------------------------------------------------------------

--- COMENTARIO IMPORTANTE ---

No se pueden dibujar los circulos con numeros cerrados
porque el enunciado no da las coordenadas del punto P.

Por eso el resultado queda en funcion de x, y, z.

Si el examen diera un punto, por ejemplo P(1,2,3),
se sustituirian x, y, z y ya saldrian los circulos
con centros y radios numericos.
