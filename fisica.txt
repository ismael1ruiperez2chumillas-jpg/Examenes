--- PROBLEMA: DEFORMACIONES Y TENSIONES ---

Campo de desplazamientos:

u = 4*a*x^2
v = 8*a*z^2
w = -2*a*y^2

Datos:

a = 10^-4 m^-1
E = 210 GPa
nu = 0.3

Punto:

P(1/2, 1, 1)

---

--- 1) MATRIZ DE DEFORMACION ---

La matriz de deformacion se calcula con:

eps_ij = 1/2*(du_i/dx_j + du_j/dx_i)

Es decir:

eps_xx = du/dx
eps_yy = dv/dy
eps_zz = dw/dz

eps_xy = 1/2*(du/dy + dv/dx)

eps_xz = 1/2*(du/dz + dw/dx)

eps_yz = 1/2*(dv/dz + dw/dy)

---

Calculamos derivadas:

u = 4*a*x^2

du/dx = 8*a*x
du/dy = 0
du/dz = 0

v = 8*a*z^2

dv/dx = 0
dv/dy = 0
dv/dz = 16*a*z

w = -2*a*y^2

dw/dx = 0
dw/dy = -4*a*y
dw/dz = 0

---

Sustituimos en la matriz:

eps_xx = du/dx = 8*a*x

eps_yy = dv/dy = 0

eps_zz = dw/dz = 0

eps_xy = 1/2*(du/dy + dv/dx)

eps_xy = 1/2*(0 + 0)

eps_xy = 0

eps_xz = 1/2*(du/dz + dw/dx)

eps_xz = 1/2*(0 + 0)

eps_xz = 0

eps_yz = 1/2*(dv/dz + dw/dy)

eps_yz = 1/2*(16*a*z - 4*a*y)

eps_yz = 8*a*z - 2*a*y

---

Por tanto:

[eps] =

| 8*a*x        0              0        |
|   0          0        8*a*z - 2*a*y |
|   0    8*a*z - 2*a*y        0       |

---

--- 2) DEFORMACIONES PRINCIPALES EN P ---

Punto:

P(1/2, 1, 1)

Por tanto:

x = 1/2
y = 1
z = 1

Sustituimos en la matriz de deformacion.

eps_xx = 8*a*x

eps_xx = 8*a*(1/2)

eps_xx = 4*a

---

eps_yz = 8*a*z - 2*a*y

eps_yz = 8*a*(1) - 2*a*(1)

eps_yz = 8*a - 2*a

eps_yz = 6*a

---

Como:

a = 10^-4

queda:

[eps]_P =

| 4*10^-4      0            0      |
|    0         0        6*10^-4    |
|    0     6*10^-4        0        |

---

Para obtener las deformaciones principales,
sacamos los autovalores de la matriz.

Planteamos:

| 4*a - eps      0          0      |
|    0        -eps        6*a     | = 0
|    0         6*a       -eps     |

El determinante queda:

(4*a - eps)*(eps^2 - 36*a^2) = 0

Por tanto:

4*a - eps = 0

eps = 4*a

Y tambien:

eps^2 - 36*a^2 = 0

eps^2 = 36*a^2

eps = +/- 6*a

---

Deformaciones principales:

eps_1 = 6*a

eps_2 = 4*a

eps_3 = -6*a

Como a = 10^-4:

eps_1 = 6*10^-4

eps_2 = 4*10^-4

eps_3 = -6*10^-4

---

--- DIRECCIONES PRINCIPALES ---

Para eps_1 = 6*a:

n_1 = (0, 1/sqrt(2), 1/sqrt(2))

---

Para eps_2 = 4*a:

n_2 = (1, 0, 0)

---

Para eps_3 = -6*a:

n_3 = (0, 1/sqrt(2), -1/sqrt(2))

---

--- 3) TENSOR DE TENSIONES ---

La formula del enunciado es:

sigma_ij =
E*nu/((1+nu)*(1-2*nu))*eps_kk*delta_ij
+
E/(1+nu)*eps_ij

---

Primero calculamos:

eps_kk = eps_xx + eps_yy + eps_zz

eps_kk = 8*a*x + 0 + 0

eps_kk = 8*a*x

---

Calculamos constantes elasticas:

A = E*nu/((1+nu)*(1-2*nu))

A = 210*0.3/((1+0.3)*(1-2*0.3))

A = 63/(1.3*0.4)

A = 63/0.52

A = 121.154 GPa

---

B = E/(1+nu)

B = 210/(1+0.3)

B = 210/1.3

B = 161.538 GPa

---

Entonces:

sigma_ij = A*eps_kk*delta_ij + B*eps_ij

sigma_ij = 121.154*eps_kk*delta_ij
+ 161.538*eps_ij

---

--- TENSOR DE TENSIONES GENERAL ---

sigma_xx = A*eps_kk + B*eps_xx

sigma_xx = 121.154*(8*a*x) + 161.538*(8*a*x)

sigma_xx = (121.154 + 161.538)*8*a*x

sigma_xx = 2261.536*a*x GPa

---

sigma_yy = A*eps_kk + B*eps_yy

sigma_yy = 121.154*(8*a*x) + 161.538*0

sigma_yy = 969.232*a*x GPa

---

sigma_zz = A*eps_kk + B*eps_zz

sigma_zz = 121.154*(8*a*x) + 161.538*0

sigma_zz = 969.232*a*x GPa

---

sigma_yz = B*eps_yz

sigma_yz = 161.538*(8*a*z - 2*a*y)

sigma_yz = 161.538*a*(8*z - 2*y) GPa

---

sigma_xy = 0

sigma_xz = 0

---

Como a = 10^-4, pasamos a MPa.

Recordatorio:

1 GPa = 1000 MPa

Entonces:

sigma_xx = 226.154*x MPa

sigma_yy = 96.923*x MPa

sigma_zz = 96.923*x MPa

sigma_yz = 129.231*z - 32.308*y MPa

---

Por tanto:

[sigma] =

| 226.154*x        0              0        |
|     0        96.923*x       sigma_yz    |
|     0         sigma_yz      96.923*x    |

donde:

sigma_yz = 129.231*z - 32.308*y

Unidades: MPa

---
